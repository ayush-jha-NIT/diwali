# Heeriye flute-cover asset

Place the user-provided, web-encoded MP3 at `public/audio/heeriye-flute-cover.mp3`. This repository currently contains the player implementation; until the audio file is added, the existing original piano score plays as a fallback. The app attempts autoplay on initial load but browsers may require the first tap. Host this cover publicly only if you have rights/permission for the musical composition and sound recording.
